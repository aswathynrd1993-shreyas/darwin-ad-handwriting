# DARWIN Alzheimer's handwriting – nested cross-validation

Code for the paper: "Explainable machine learning on handwriting dynamics
for classifying Alzheimer's disease: a leakage-safe nested cross-validation
study on the DARWIN dataset"

Dataset: download from https://archive.ics.uci.edu/dataset/732/darwin
Requirements: Python 3, scikit-learn, numpy, pandas, scipy, matplotlib
Random seed: 42
